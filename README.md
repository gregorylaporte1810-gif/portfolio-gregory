Portfolio personnel réalisé avec React et Vite pour présenter mon parcours, mes compétences et mes projets de développement web.

## 🌐 Démonstration

**Site en ligne :** [gregory-dev-portfolio.netlify.app](https://gregory-dev-portfolio.netlify.app/)

Le portfolio est accessible sur ordinateur, tablette et mobile.

## 🚀 Installation en local

### Prérequis

- Node.js compatible avec Vite 8
- npm
- Git

### Étapes

Cloner le dépôt :

```bash
git clone https://github.com/gregorylaporte1810-gif/portfolio-gregory.git
```

Accéder au dossier :

```bash
cd portfolio-gregory
```

Installer les dépendances :

```bash
npm install
```

Démarrer le serveur de développement :

```bash
npm run dev
```

Ouvrir ensuite l'adresse affichée dans le terminal, généralement :

http://localhost:5173/

## 📜 Commandes disponibles

| Commande | Description |
|---|---|
| `npm run dev` | Démarrer le serveur de développement |
| `npm run build` | Générer la version de production |
| `npm run preview` | Prévisualiser la version de production |
| `npm run lint` | Vérifier le code avec ESLint |

## 📱 Responsive design

Le portfolio a été conçu pour s'adapter à plusieurs tailles d'écran :

- **Ordinateur :** navigation classique et affichage en plusieurs colonnes
- **Tablette :** réorganisation des sections et des cartes
- **Mobile :** menu hamburger et affichage des cartes sur une seule colonne

## ♿ Qualité et accessibilité

Le projet utilise une structure HTML sémantique, des attributs d'accessibilité pour la navigation et des textes alternatifs pour les images.

Le code est contrôlé avec ESLint.

Des audits Lighthouse ont également été réalisés pour évaluer les performances, l'accessibilité, les bonnes pratiques et le référencement.

## 🌍 Déploiement

Le site est déployé sur **Netlify** et connecté au dépôt GitHub.

Les modifications envoyées sur la branche `main` déclenchent automatiquement un nouveau déploiement.

- **Branche :** `main`
- **Commande de build :** `npm run build`
- **Dossier de publication :** `dist`
